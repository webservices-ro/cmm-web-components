A permanent therapeutic workshops page powered by WooCommerce products.

== Installation ==

1. Upload the plugin ZIP in Plugins > Add Plugin > Upload Plugin.
2. Activate CMM Components.
3. The plugin creates the Ateliere terapeutice page and its WooCommerce category automatically.
4. Assign workshop products to the Ateliere terapeutice product category.
