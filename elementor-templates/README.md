# Elementor homepage template

1. Install or update the **Claudia Maria React Components** plugin first. The
   template depends on its `Claudia Maria Homepage` Elementor widget.
2. In WordPress, open **Templates → Saved Templates → Import Templates** and
   import `claudia-maria-homepage.json`.
3. Create a private draft page, click **Edit with Elementor**, open the Template
   Library, choose **My Templates**, and insert `Claudia Maria — Homepage`.
4. In Page Settings, use **Elementor Full Width** (keep the theme header/footer)
   or **Elementor Canvas** (no theme header/footer), as appropriate.
5. Edit the widget. Each homepage area has its own Elementor content panel;
   colors and content width are under **Style**.

Do not make the draft the WordPress homepage until its links, mobile layout,
SEO fields, analytics, forms/popup, and structured data have been checked.
